# BountyPulse-Decentralized-Micro-Bounty-Escrow-
BountyPulse is a decentralized micro-bounty platform powered by Ethereum smart contracts and escrow-based payments. Users can post bounties, submit work, and securely manage payments without a centralized intermediary. IPFS provides decentralized file storage, while blockchain ensures transparent and tamper-resistant transactions.

### Implementation Details
- **Frontend**: Built with **Next.js** (App Router), Tailwind CSS, and `ethers.js` instead of Vite.
- **Smart Contracts**: Built and tested with **Foundry** instead of hardhat, featuring full Escrow & Registry Logic.
- **Micro-UX**: Includes clear ARIA labels, semantic HTML structure, and loading spinners for Web3 transaction feedback.
